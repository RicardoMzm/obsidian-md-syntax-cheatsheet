# Markdown 语法对照表

写 Obsidian 的时候老是记不住某个语法？点一下工具栏的书本图标，左边看写法，右边看效果，照着抄就行 (｡･ω･｡)

## 有什么

- 77 条常用语法，分成标题、文本样式、列表、引用、链接、图片、代码、表格、数学公式、Obsidian 专有语法等 11 类
- 左边显示原始写法，右边直接渲染出效果
- 点一下左边的代码块就能复制
- 顶部搜索框可以按关键词过滤，比如 `表格`、`callout`、`脚注`
- 支持右侧边栏、左侧边栏、主区域标签页，另外还有一个弹窗模式

## 安装

把 `md-syntax-cheatsheet` 文件夹放到：

```
你的库/.obsidian/plugins/md-syntax-cheatsheet/
```

然后在 `设置 → 第三方插件` 里刷新一下，打开「Markdown 语法对照表」的开关。

文件夹里需要这三个文件：`manifest.json`、`main.js`、`styles.css`。

## 怎么用

- 点左侧工具栏的书本图标（开启时图标会高亮，再点一次关掉）
- `Ctrl/Cmd + P` 搜「Markdown 语法对照表」
- 设置里可以改打开位置、预览字号、要不要显示搜索框和状态栏按钮

## 想自己加语法

打开 `cheatsheet-data.ts`，在对应分类里加一条：

```ts
{ syntax: "语法的原始写法", desc: "中文说明" }
{ syntax: "左侧显示的写法", desc: "说明", preview: "右侧真正渲染的内容" }
```

改完跑一下：

```bash
npm run build
```

然后重启插件就能看到。开发的时候用 `npm run dev`，改完会自动重新打包。
